# christmas-tree-v17.6 🎄

一棵可以拖动旋转的粒子圣诞树，单文件 HTML，无依赖、可离线运行。

## 用法

- 电脑打开 `index.html` 即可。
- 鼠标左右拖动可以手动转动圣诞树，松手后自动缓慢旋转。
- 想把祝福送给某个人的名字，用链接参数即可：`index.html?name=小美`，
  页面上会显示「— 献给 小美 —」。
- 手机竖屏、电脑横屏都做过适配。

## 技术

纯 Canvas 2D：锥形粒子树身 + 螺旋彩灯（各自独立的闪烁相位）+ 飘雪 + 金色光尘 +
透视投影与深度排序，`requestAnimationFrame` 驱动，无第三方库、无外部资源。

## 部署

已通过 GitHub Pages 发布，入口为仓库根目录的 `index.html`。

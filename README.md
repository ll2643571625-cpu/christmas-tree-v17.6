# christmas-tree-v17.6 🎄

一棵可以拖动旋转、并且能感应你动作的粒子圣诞树。单文件 HTML，无依赖、可离线运行。

线上地址：https://ll2643571625-cpu.github.io/christmas-tree-v17.6/

---

## 怎么在线编辑（不用装任何软件）

1. 打开仓库 https://github.com/ll2643571625-cpu/christmas-tree-v17.6
2. 点开 `index.html`，右上角点铅笔图标 ✏️（Edit this file）
3. 改完往下拉到 **Commit changes**，直接点绿色按钮提交（提交信息随便写，比如「改名字」）
4. 等 1 分钟左右，GitHub Pages 会自动重新构建，刷新线上链接就能看到新效果

> 想改文案只要改 `index.html` 里 `var CONFIG = {...}` 那几行：
> `name` 祝福对象、`merry` 第一行大字、`cn` 第二行小字、
> `autoRotate` 旋转速度、`camera` 是否显示摄像头按钮（`false` 就隐藏）、
> `cameraSensitivity` 动作灵敏度（默认 14，觉得不灵就调大，觉得乱闪就调小）、
> `burstOnTap` / `burstOnMotion` 是否用点击、动作触发炸开。

更顺手的方式：在仓库页面按键盘 **`.`**（句号）会打开 VS Code 网页版（github.dev），
可以像本地编辑器一样改、看高亮，改完在左侧源代码管理面板一键提交。

## 交互：点一下 / 挥一下，圣诞树炸开

- **点一下屏幕**（不拖动）：整棵树瞬间炸开成漫天星尘，顶部星星放闪、冲击波散开，
  约 2.6 秒后粒子沿原路缓缓归位，重新长回圣诞树。
- **开着摄像头时大幅挥手/走动**：动作强度越过阈值同样会触发炸开。
- 触发后有 0.7 秒左右的冷却，动画没结束不会重复触发。
- 想关掉：`CONFIG.burstOnTap: false`（关点击）或 `CONFIG.burstOnMotion: false`（关动作触发）。

## 摄像头互动怎么用

- 打开网页 → 右下角点「**开启摄像头互动**」→ 浏览器弹出权限请求，点允许。
- 摄像头画面会变成一层很暗的冷蓝色背景，像隔着一层磨砂玻璃，你的轮廓在里面若隐若现。
- 挥手 / 走动 / 晃头：树上的彩灯会整体变亮、闪烁变快，星星变亮，还会向上飞出金色火花；停止动作后慢慢恢复。
- 再点一次按钮即可关闭摄像头（本地立即停止采集，画面不会上传到任何服务器）。
- 手机端同样支持，iOS Safari / 安卓 Chrome 都可以，必须是 **https** 链接（本项目已是 https）。

### 原理（简述）

每帧把摄像头画面缩到 64×48 的小画布，逐像素比较前后两帧亮度差，
累加得到「动作强度」；再把这个 0~1 的数值平滑后驱动彩灯亮度、闪烁相位、旋转速度、
星星脉冲和火花生成——所以是「动作越大，树越兴奋」，不需要任何 AI 模型。

## 用法

- 电脑/手机打开 `index.html` 即可。
- 鼠标或手指左右拖动可以手动转动圣诞树，松手后自动缓慢旋转。
- 想把祝福送给某个人：链接后加 `?name=小美`，页面显示「— 献给 小美 —」。
- 手机竖屏、电脑横屏都适配过。

## 技术

纯 Canvas 2D：锥形粒子树身 + 螺旋彩灯（各自独立闪烁相位）+ 飘雪 + 金色光尘 +
透视投影与深度排序，摄像头画面经 `getUserMedia` 作为背景纹理并做动作识别，
`requestAnimationFrame` 驱动，无第三方库、无外部资源。
